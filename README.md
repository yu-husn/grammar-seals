# 語法禁域：四句封印

國中國文四大句型的3D冒險遊戲：敘事句、表態句、判斷句、有無句。

**線上遊玩：[開啟遊戲](https://yu-husn.github.io/grammar-seals/)**

不需安裝或登入，電腦、平板及手機瀏覽器皆可開啟。建議使用支援WebGL的新版瀏覽器。

## 冒險內容

- 約40秒六幕3D序章：無言君與四大關主佔領大地，辨句使者躲避追擊、辨句、善用道具，讓大地重拾生機。可暫停、跳過、重播；音效由玩家點選後才播放。
- 主角二選一：沈墨、蘇映；各關主具有不同造型。
- 路線：行跡迷城 → 靈印寶石陣 → 幻象迷宮 → 真假審判 → 句型石轟擊 → 虛實禁域 → 無言君決戰。
- 四域各6題、魔王16題，共40題計分，每題2.5分，滿分100分；首答正確全分，補救答對半分。
- 兩個必經補給站各7題，不計學科成績，各限一局、最多100點，合計最多200點兌換道具；兩站點數分開計算。
- 句型石轟擊採古銅單管砲台：固定底座、轉向瞄準、砲管後座力與砲口火光。
- 每卷共54道不同句子，隨機抽題並保留教師新增題優先；續玩、重試及補救不重抽。入口「重新計分」後才重新抽題。
- 四域起始200秒、魔王240秒。讀題、解析、暫停及開場動畫不扣探索時間。
- 無言君生命歸零後會倒下、化為靈光消散；觀看動畫及等待最後封印時不再扣時或受傷，結局畫面會等動畫完成。
- 入關依序查看行旅地圖、複習句型後直接開始；不再顯示任務與出發道具說明頁。
- 各關任務清單可從主選單「遊玩指引」自行開啟查看。
- 六種道具：疾風靴、縛魔索、逆時珠、誅邪彈、金鐘罩、延命丹。主選單「道具介紹」可看圖片與完整效果。
- 教師後台可調整難度、追擊及音效，查看成績、下載本卷隨機40題與答案，並匯出CSV。

## 操作

電腦：WASD／方向鍵移動、拖曳轉向、E互動、空白鍵閃避、數字鍵1–6使用道具。手機／平板：畫面搖桿、互動、轉向、閃避及道具按鈕。

所有學習紀錄、成績與進度只保存在使用者自己的瀏覽器，不會上傳GitHub，也不會跨裝置同步。清除網站資料或使用無痕模式可能失去存檔。本機試玩網址與GitHub Pages是不同來源，存檔不會自動搬移。

## 本機開發

使用Node.js 24與pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

React、TypeScript、Vite、Three.js、React Three Fiber、drei、Zustand、GSAP與Howler.js。遊戲邏輯、題庫、場景、介面及開場動畫分開維護。

## GitHub Pages部署

推送至預設分支codex/publish-game後，GitHub Actions會安裝依賴、執行測試、建置並部署Pages。使用專案子路徑/grammar-seals/；scripts/build-github-pages.mjs同時修正字型、音樂、道具、題庫與指南的資源網址。

本機驗證Pages建置可執行pnpm build:pages。dist是產物，不提交至原始碼。更換儲存庫名稱時，工作流程會由GITHUB_REPOSITORY自動取得新的子路徑。

本儲存庫包含目前遊戲及150項邏輯／題庫測試。工作站的瀏覽器存檔、測試截圖、學習紀錄、原始來源擷取頁與歷史刪題交付檔均不公開。
